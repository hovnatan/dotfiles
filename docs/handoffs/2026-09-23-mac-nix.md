# Handoff: move the Mac's CLI tools from Homebrew to Nix

Written 2026-09-23 on vm (Linux), where all of this is done and
verified. The Mac is the remaining machine. Work through the steps in order;
each ends with a **Done when** check -- do not start the next step until it
holds. Steps marked **(user)** need sudo: agent shells have no tty, so hand
the commands to the user to run in their own terminal and wait for them.

## What changed and why

Goal: Linux boxes and the Mac nearly identical. Commits `b627f46b..ba1e23d1`
on `main` (read them with `git log -p`); the ones that touch the Mac:

- `nix/flake.nix` is now the one CLI package list for Linux and macOS
  (`aarch64-darwin`). Everything is in `common`; the only per-OS entry is
  zsh on Linux. The `Brewfile` keeps casks, App Store apps, VS Code
  extensions, `mas` and `duti` -- its 19 other formulae moved to Nix.
- Nix's `bash` replaces brew's (scripts use `#!/usr/bin/env bash`), Nix's
  `pandoc` replaces brew's, and Node is **24 LTS** (brew's `node` was 26),
  because `deqart_web` pins 24.
- hunspell comes from Nix with its en_US dictionary built in;
  `scripts/macos/setup_hunspell.sh` (brew + LibreOffice download) is gone.
- `dotup` now runs a Nix step on macOS too (`nix profile upgrade` when the set
  is installed; an error when Nix is installed but not on PATH).
- `home/.profile.shared` holds the shell-neutral exports (EDITOR, LANG,
  WORDLIST, COLORTERM, MAKEFLAGS, `~/.local/bin` on PATH); the installer
  appends a line sourcing it to `~/.profile`, which `.zprofile` reads.
- fish and nvim configs are restored and linked (`~/.config/fish`,
  `~/.config/nvim`, `~/.config/fd`); fish, fzf, fd, neovim, ripgrep now come
  from Nix on the Mac too.
- Ghostty: `keybind = ctrl+m=text:\r` (Ghostty sends ctrl+m as `ESC[109;5u`
  by design; fzf outside tmux typed "109;5u").

Expected after migration (from the pinned nixpkgs): azure-cli 2.89.1, bash
5.3p15, fd 10.5.0, fish 4.9.3, fzf 0.74.4, gh 2.101.0, gws 0.22.5, htop
3.5.3, hunspell 1.7.3, imagemagick 7.1.2-31, lftp 4.9.3, mediainfo 26.05,
mosh 1.4.0, neovim 0.12.5, node 24.20.0, pandoc 3.7.0.2, poppler-utils
26.06.0, rclone 1.75.1, ripgrep 15.2.0, rsync 3.5.0, shellcheck 0.11.0,
tmux 3.7c, typst 0.15.1, uv 0.12.17, wget 1.25.0.

## Steps

### 1. Snapshot the current state

```
uname -m                                   # must be arm64 -- the flake has no Intel Mac build
dscl . -read ~ UserShell
brew list --formula > ~/pre-nix-brew-formulae.txt
for t in az bash gh gws htop hunspell magick lftp mediainfo mosh node pandoc \
         pdftotext rclone rsync shellcheck tmux typst uv wget fish nvim rg fd fzf; do
  printf '%-11s %s\n' "$t" "$(command -v $t || echo -)"; done > ~/pre-nix-which.txt
npm ls -g --depth=0 > ~/pre-nix-npm-globals.txt 2>&1
az extension list -o table > ~/pre-nix-az-extensions.txt 2>&1
ls -l ~/.local/bin/uv ~/.local/bin/uvx 2>&1
```

**Done when** the four `~/pre-nix-*.txt` files exist and `uname -m` said
`arm64` (if not, stop and report: add `x86_64-darwin` to the flake first).

### 2. Pull and re-install: `dotup`

Runs the pull, `setup_user_symlinks.sh`, the Brewfile drift report and the
Nix step. Expected on this first run:

- a warning if `~/.config/fish`, `~/.config/nvim` or `~/.config/fd` is a real
  directory: look inside, move it aside if it holds nothing you need, re-run;
- the drift report lists the 19 moved formulae as "installed, not listed" --
  correct until step 6;
- the Nix step is silent (Nix is not installed yet).

Then reload Ghostty's config (`cmd+shift+,`).

**Done when** `dotup` exits 0 (or only with the expected drift), `~/.profile`
ends with the `.profile.shared` block, and `ls -l ~/.config/{fish,nvim,fd}`
shows links into `~/.dotfiles/home/.config/`.

### 3. Install Nix (user)

```
sh <(curl -fsSL https://releases.nixos.org/nix/nix-2.35.2/install) --daemon --yes
echo 'experimental-features = nix-command flakes' | sudo tee -a /etc/nix/nix.conf
sudo launchctl kickstart -k system/org.nixos.nix-daemon
```

The installer creates an APFS volume for `/nix`, the `nixbld` users and a
launchd daemon, and hooks `/etc/zshrc` and `/etc/bashrc`.

**Done when**, in a new terminal (`exec zsh -l`), `nix --version` prints
2.35.2 and `nix config show experimental-features` includes `flakes`.

### 4. Install the package set

```
nix profile add path:$HOME/.dotfiles/nix
nix profile list
```

**Done when** `nix profile list` shows one entry named `nix` from
`path:/Users/<you>/.dotfiles/nix`, and `ls ~/.nix-profile/bin` contains
tmux, node, pandoc, bash, hunspell and the rest of the list above.

### 5. Make sure bash can go

If step 1's `UserShell` is `/opt/homebrew/bin/bash`, the login shell dies with
brew's bash. Switch first (user): `chsh -s /bin/zsh` (or add
`~/.nix-profile/bin/bash` to `/etc/shells` and `chsh` to that).

**Done when** `dscl . -read ~ UserShell` is not under `/opt/homebrew`.

### 6. Retire the Homebrew copies

Read the `Brewfile` header first: `brew uninstall` autoremoves orphaned
dependencies (it once took 50 formulae with it).

```
brew autoremove --dry-run
brew uninstall azure-cli bash gh googleworkspace-cli htop hunspell imagemagick \
  lftp media-info mosh node pandoc poppler rclone rsync shellcheck tmux typst uv wget
brew missing
```

`hunspell` was never in the Brewfile (setup_hunspell.sh installed it); skip
any name brew says is not installed.

**Done when** `brew list --formula` has none of those names, `brew missing`
prints nothing, and a new `dotup` shows no drift for them.

### 7. Remove the standalone uv

`~/.local/bin` precedes Nix on PATH, so a self-installed uv there hides Nix's.

```
cat ~/.config/uv/uv-receipt.json      # the installer's record; "install_prefix" should be ~/.local/bin
rm ~/.local/bin/uv ~/.local/bin/uvx ~/.config/uv/uv-receipt.json
```

The receipt lives in the dotfiles repo's `home/.config/uv/` (gitignored).
**Done when** `command -v uv` is `~/.nix-profile/bin/uv` and `uv --version`
says 0.12.17 (skip the step if step 1 found no `~/.local/bin/uv`).

### 8. Verify, tool by tool

In a new login shell:

```
for t in az bash gh gws htop hunspell magick lftp mediainfo mosh node pandoc \
         pdftotext rclone rsync shellcheck tmux typst uv wget fish nvim rg fd fzf; do
  printf '%-11s %s\n' "$t" "$(command -v $t || echo MISSING)"; done
echo recieve | hunspell -l -d en_US       # prints "recieve"
node -v                                   # v24.20.0
npm ls -g --depth=0                       # compare with ~/pre-nix-npm-globals.txt
az extension list -o table                # compare with ~/pre-nix-az-extensions.txt
```

**Done when** every tool resolves under `~/.nix-profile/bin`, hunspell flags
"recieve", and the npm globals and az extensions match the snapshots. npm
globals live under `~/.local` (`home/.npmrc`), so they survive Node's move;
any with a native addon was built for Node 26 and needs a reinstall
(`npm install -g <pkg>`) if it fails to load. An `ENOENT ... ~/.local/lib`
error from `npm ls -g` just means there are no npm globals.

### 9. Check the terminal fixes

- In fish (`fish`), press `ctrl-o` (file picker), then `ctrl-m`: it accepts
  instead of typing "109;5u".
- `nvim` starts with no errors (`nvim --headless +qa`).
- Optional cleanup: `rm ~/Library/Spelling/en_US.{aff,dic}` (the old
  LibreOffice dictionary; Nix's hunspell carries its own).

**Done when** both behave as described.

### 10. Report back

Summarise: which steps ran, anything that deviated from the expectations
above, the step 8 output, and any tool that did not end up under
`~/.nix-profile/bin`. Then delete the `~/pre-nix-*.txt` snapshots.

## Gotchas

- **PATH order.** `home/.zprofile` sources the Nix profile before `~/.profile`,
  so the order is `~/.local/bin`, then Nix, then the rest. If a machine-local
  `~/.zprofile` line runs `brew shellenv` after the dotfiles block, brew's
  directory comes first -- harmless once step 6 is done, confusing before.
- **macOS updates rewrite `/etc/zshrc`** and can drop Nix's hook there;
  login shells still get Nix through `home/.zprofile`.
- **GUI-launched programs** (launchd, Hammerspoon) do not read shell profiles;
  none in this repo run bash scripts, but anything new that does must call
  `~/.nix-profile/bin/bash` explicitly -- `/bin/bash` is 3.2.
- **Versions move only with the lock.** Nix will not update tools on its own;
  bump with `nix flake update --flake path:$HOME/.dotfiles/nix`, commit
  `nix/flake.lock`, and `dotup` everywhere.

## Rollback

```
nix profile remove nix
brew bundle --file=<(git -C ~/.dotfiles show 56e7def2^:Brewfile)
```

That reinstalls the pre-migration formulae; Nix itself stays until removed
per https://nix.dev/manual/nix/stable/installation/uninstall.html.
