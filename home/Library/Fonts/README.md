# Fonts

CommitMono500-*.otf: iTerm2's font (Commit Mono at weight 500, bold 700),
relinked into one 4-style family by `scripts/macos/build_commit_mono500.py`,
whose docstring has the source revision and the rebuild commands.
`scripts/setup_user_symlinks.sh` copies the .otf files into ~/Library/Fonts.
